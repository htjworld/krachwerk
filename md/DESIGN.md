# Krachwerk Design System

다크, 미니멀, 일렉트로닉. TJ의 GitHub 프로필 배너 SVG(터미널 톤)에서 뽑은 팔레트를 그대로 쓴다.
자세한 배경과 출처는 `Krachwerk_개발_기획서.md` 2.2.1을 참고한다.

## Color

### 웹앱 (Phase 1, 다크 전용)

| Token | Value | Usage |
|---|---|---|
| `--bg-device` | `#0d1117` | 디바이스(생성기) 배경 |
| `--fg-device` | `#75fb4c` | 디바이스 전경, 활성 셀 (메인 네온그린) |
| `--fg-device-dim` | `#5bc43b` | 비활성 셀, 보조선 |
| `--bg-ambient-a` | `#fafaf8` | 바깥 배경 색상 A |
| `--bg-ambient-b` | `#75fb4c` | 바깥 배경 색상 B |
| `--accent-blue` | `#58a6ff` | 링크, hover/focus, 강조 텍스트 (배경 애니메이션에는 쓰지 않는다) |
| `--panel` | `#21262d` | 디바이스 안 패널 구분선, 버튼 배경 |
| `--playhead` | `#3a3a3a` | 재생 위치 표시 바 |

### 후보색 (메인 팔레트로 부족할 때만, 이 순서로)

`--ref-cyan #00d4e8`, `--ref-magenta #ff0090`, `--ref-gold #d29922`,
`--ref-kakao-yellow #FEE500`(마케팅 소재 금지, UI 강조용만), `--ref-muted-1 #8b949e`, `--ref-muted-2 #6e7681`.

배경 전환은 항상 `--bg-ambient-a` ↔ `--bg-ambient-b` 2색 순환만 쓴다. 파란색은 3순위 액센트로만
쓰고 배경 순환에 넣지 않는다.

## Typography

- 디바이스 영역: `"Courier New", monospace`. 한글 라벨이 필요하면
  `"Courier New", "D2Coding", "Noto Sans Mono CJK KR", monospace`.
- 프레임/설명 텍스트: 시스템 기본 산세리프, 일반 대소문자.
- 디바이스 버튼 라벨(`SEED`, `SHUFFLE`, `SHARE`, `RESET` 등)은 레트로 하드웨어 UI를 흉내 내는
  의도적 장치라 전부 대문자를 쓴다. 문장형 카피, 설명 텍스트는 절대 전부 대문자로 쓰지 않는다.

## Motion

바깥 배경은 10초 주기로 `--bg-ambient-a`와 `--bg-ambient-b` 사이를 오간다. 페이드 없이
`step-end`로 5초마다 딱 끊어서 바꾼다(기계가 스위치를 치는 느낌). 전환 주기가 0.1Hz라
광과민성 기준(3Hz)과는 거리가 멀지만, `prefers-reduced-motion: reduce`에서는 애니메이션을
끄고 `--bg-ambient-a` 고정 배경만 보여준다.

## Tone

- 가운데 점, 긴 대시(이중 하이픈), 문장/버튼 끝 화살표 기호를 쓰지 않는다.
- 라벨을 전부 대문자로 쓰지 않는다(디바이스 버튼 예외).
- 강조를 위해 한 단어만 굵게/기울임으로 처리하는 습관, 내용과 무관한 눈썹 라벨을 쓰지 않는다.
- 이모지를 쓰지 않는다. 아이콘/일러스트가 필요하면 실제 소스를 찾아 쓴다.
- 모든 문구는 해요체, 능동형, 긍정형으로 쓴다. `~시겠어요?`, `~께` 같은 과도한 경어를 쓰지 않는다.
- 다이얼로그의 취소 쪽 버튼 라벨은 `닫기`로 통일한다.
- CTA 버튼 라벨은 결과를 그대로 서술한다(`다운로드하기`, `공유 링크 만들기`).

## Layout

한글/영어 두 언어를 지원한다(5.4). 기본 언어는 브라우저 설정을 감지하고, 감지 실패 시 한국어로
fallback한다. 시드값과 `pattern` URL 파라미터는 언어와 무관하게 항상 동일하다.
